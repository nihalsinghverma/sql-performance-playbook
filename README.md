# SQL Performance Playbook

## Problem

SQL performance work is frequently reactive because query tuning guidance is disconnected from measurable execution evidence.

## What's included

Query tuning checklists, indexing patterns, execution-plan interpretation, anti-patterns, and database-specific notes.

## How to run

Clone the repository and follow the instructions in its examples or project files. Python examples use Python 3.11+ and should be run from an isolated virtual environment.

`powershell
git clone https://github.com/nihalsinghverma/sql-performance-playbook.git
cd sql-performance-playbook
`

## Outputs

Optimized query examples, diagnostic checklists, and repeatable performance review workflows.

## Design notes

Recommendations should be validated against actual plans, data distributions, and workload characteristics.

## Roadmap

Add benchmark datasets, engine-specific labs, and automated plan-diff tooling.
